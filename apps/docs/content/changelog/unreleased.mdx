## Patch changes

### No motion on keyboard and high-frequency surfaces, where any duration reads as lag:

- Dropdown menus (and sub-menus), Popover and Tooltip open and close instantly whenever Base UI marks the popup `data-instant`: a menu or popover opened from the keyboard or dismissed with Escape, a tooltip opened on focus, closed on press/Escape, or hopping between triggers in a delay group. Pointer opens keep their transition.
- `CommandDialog` content appears and leaves at once (it now carries `data-command`, which `base.css` keys on). The overlay keeps its short fade.
- Tabs' morphing pill and label settle without bounce (same 400ms spring, `bounce: 0`), and the label's fade runs on its own 125ms tween while its width stays on the spring.
- Focus rings on Input, InputGroup, Textarea, InputOTP, Select, NativeSelect and Tag's remove button are instant: `box-shadow` is out of their transition lists. Table rows no longer transition their hover background.
- `dashboard-01` and `admin-01` charts animate once on mount (400ms, ease-out) instead of replaying a 1.5s entrance on every legend toggle or range change, via a `useMountOnlyAnimation` hook next to `useReducedMotion`.
- `admin-01`'s sidebar toggles instantly from the ⌘B / Ctrl+B shortcut; the click path moves from `duration-200 ease-linear` to the `--duration-base` / `--ease-ks-out` tokens.

---

### Mobile-native polish:

- **No focus zoom on touch.** Input, Textarea, InputOTP, InputGroup, DateInput, NativeSelect, CommandInput, Combobox and ComboboxChips render at 16px under a coarse pointer and 14px only under a fine pointer (`pointer-fine:text-sm`). The old `md:text-sm` gate keyed off width, so iPads — wide, but touch — zoomed on every field, and NativeSelect, CommandInput and ComboboxChips were 14px everywhere. Mouse and trackpad users still see 14px; touch devices get 16px at every width. Control heights come from `--ks-control-*` and are unchanged.
- **Modal `scrollBehavior="inside"`** caps the popup at `calc(100dvh - 2rem)` and scrolls it, so long content no longer runs off a phone screen with nothing to scroll.
- **Drawer** top/bottom caps use `80dvh` instead of `80vh`, so the sheet tracks the mobile URL bar instead of hiding under it.
- **Carousel**: the track sets `touch-action: pan-y pinch-zoom` (`pan-x` when vertical), so a vertical swipe across a horizontal carousel scrolls the page. Auto-hidden arrows are always visible on touch and when focused from the keyboard. Dots keep their 8px look with a 24px-tall hit area.
- **Button and Toggle** drop the grey `-webkit-tap-highlight-color` flash; both already have their own `active:` feedback.
- **ResizableHandle** hit area widens from 4px to 12px.
- **CommandInput** defaults `enterKeyHint="search"` (overridable).
- Sign-in and sign-up blocks set `autoComplete` and `enterKeyHint` on their fields.

Drawer, Toast and SelectionBar's `env(safe-area-inset-*)` padding only applies when the page sets `viewport-fit=cover`; the installation guide now says so.

### Raise the `motion` dependency floor to `^14.6.0`. Since 14.2, Motion runs `x`/`y` animations on the compositor, so Stepper's slide no longer drops frames when the main thread is busy. It also dedupes with the version the docs already used.

---

### Motion that read as animated but snapped now animates, and every transition times itself from the motion tokens:

- Tailwind v4's `scale-*` / `translate-*` set the standalone `scale` / `translate` properties, so `transition-[transform,…]` never animated them. Button's press, the Checkbox and Radio indicators, the Slider thumb's drag grow and SelectionBar's rise now transition (`transition-[scale,…]` / `[translate,…]`).
- Checkbox's indicator now animates out on uncheck (it was hidden instantly) and, like Radio's, starts from `scale(0.9)` instead of `0.5`.
- SelectionBar's enter now plays: it mounts into the visible state with `@starting-style` from-values instead of a batched rAF, exits faster than it enters, unmounts on `transitionend`, and drops its permanent `will-change`. Uses `--ease-ks-out` instead of a private curve.
- Literal `duration-150` / `duration-200` / `duration-[160ms]` / `duration-100` across Accordion, Collapsible, Carousel dots, Checkbox, Radio, Switch, Input, Select, Item and Button now resolve to `--duration-fast` / `--duration-base`.
- Switch thumb moves on `--ease-ks-in-out`; Toggle gets the same `active:` press scale as Button; Dropdown sub-menus get the 4px slide toward their trigger like every other popup.
- CopyButton crossfades its copy/check icons; FieldError fades in (opacity only).

---

### Survive worst-case content and make the popup z-index scale real.

- **Popup layering**: Select, Combobox, DropdownMenu (and its submenus), Popover and Tooltip put `isolate z-50` on the Base UI Positioner, which scoped the popup's own `--z-popover` / `--z-dropdown` / `--z-tooltip` z-index to that stacking context. Every popup actually sat at 50, level with an open Modal, and a tooltip could not rise above a dropdown. The token now lives on the Positioner (`z-(--z-popover,60)` and friends), so the documented 60 / 70 scale applies.
- **Select**: a long value now ellipsizes inside the trigger instead of pushing the chevron out of it (`SelectTrigger` gains `min-w-0 max-w-full`, `SelectValue` is a block that ellipsizes). Long option labels ellipsize too: `SelectItem`'s label no longer has `shrink-0`. The popup is capped at `--available-width`.
- **Popup rows**: plain-text labels in `ComboboxItem`, `CommandItem` and the DropdownMenu items are wrapped in a span that ellipsizes, so a long email no longer overflows a fixed-height row. Rows stay 36px; for a two-line row pass `className="h-auto min-h-9 py-1.5"`.
- **Popup width**: DropdownMenu, its submenus and Popover are capped at `--available-width`, so they never grow past the viewport on a phone.
- **Pagination**: `PaginationLink` without a `size` is now an `sm` button with a square minimum (`min-w-(--ks-control-sm) px-2`) instead of a fixed `icon-sm` square, so a page like `1,284` widens the link rather than spilling out of it. An explicit `size` still wins.
- **Tag / ComboboxChip**: no longer `shrink-0`; they cap at their container (`max-w-full min-w-0`) and their text label ellipsizes while the remove button stays visible.
- **Tooltip / Breadcrumb**: unbroken strings (URLs, emails) now wrap anywhere instead of overflowing; breadcrumb items get `min-w-0`.
