An `AGENTS.md` file in your project root tells AI assistants how to use Keystone UI, with no skill to install and no URL to fetch. This guide downloads it. The file is generated from the same component registry that powers the docs site, so a fresh download always lists the current components. [Choose an integration](/docs/agents/choose-an-integration) compares it with the other options.

## Download the file

Run this in your project root:

```bash
curl -o AGENTS.md https://keystoneui.io/agents-md
```

It downloads a Markdown file that any AI assistant can read. To update it later, run the same command again.

## Check that it works

Open `AGENTS.md`. It should contain:

- **Package declaration**: tells the AI this project uses Keystone UI
- **Import patterns**: subpath imports for all components
- **Full component list**: every available component with its import path
- **Theming reference**: semantic tokens, OKLCH color space, dark mode
- **CSS setup**: how to configure Tailwind CSS v4 with Keystone UI
- **Key constraints**: Base UI (not Radix), lucide-react for icons, and similar rules

Then ask your assistant to add a Keystone UI Button. It should import it from `@keystoneui/react/button`.
