We publish [LLMs.txt](https://llmstxt.org/) files so AI coding assistants can read the Keystone UI docs as plain text. This guide picks a file and hands it to your assistant. [Choose an integration](/docs/agents/choose-an-integration#llmstxt) explains how the files are built and how fresh they are.

## Pick a file

Each file covers a different slice of the docs:

- [`/llms.txt`](/llms.txt): a quick reference index for the Keystone UI docs
- [`/llms-full.txt`](/llms-full.txt): the complete Keystone UI docs
- [`/llms-components.txt`](/llms-components.txt): the component docs only

For one page, append `.mdx` to any docs path to get its plain-text version. For example, [`/docs/components/button.mdx`](/docs/components/button.mdx) is the Button page.

## Add the docs to Cursor

Add a rule that points Cursor at the component docs:

```markdown title=".cursor/rules/keystoneui.mdc"
---
description: Keystone UI component library reference
alwaysApply: true
---

Use Keystone UI for all UI components. Reference: https://keystoneui.io/llms-components.txt
```

Or download the full docs into a rule file:

```bash
curl -o .cursor/rules/keystoneui-docs.md https://keystoneui.io/llms-full.txt
```

## Give the docs to Claude or ChatGPT

Paste the contents of `/llms-full.txt` or `/llms-components.txt` as context, or reference individual component pages:

```text
https://keystoneui.io/docs/components/button.mdx
```

## Reference the docs from AGENTS.md

Add this section to your project's `AGENTS.md`:

```markdown
## UI Library

This project uses Keystone UI for components.
Documentation: https://keystoneui.io/llms-components.txt

Import pattern: `import { Button } from "@keystoneui/react/button"`
```

## Check that it works

Ask your assistant how to import a Keystone UI Button. It should answer with the subpath import, `import { Button } from "@keystoneui/react/button"`, not a barrel import from `@keystoneui/react`.
