title: Troubleshoot the MCP server
description: Fix the Keystone UI MCP server when it doesn't show up in your editor, shows no tools, or can't load components.

---

This page covers the 3 problems you're most likely to hit after [setting up the MCP server](/docs/agents/mcp-server). Find the symptom you see, then apply the fix.

## The server doesn't show up in the editor

**Cause**: the editor didn't find or didn't load the config file, or the server is disabled.

**Fix**:

1. Check that the config file exists in the right location for your editor ([Set up the MCP server](/docs/agents/mcp-server#write-the-config-by-hand) lists them).
2. Restart your editor after adding the configuration.
3. In Cursor, check **Settings > MCP Servers** and enable the server.

## The server shows no tools

**Cause**: a stale `npx` cache or a server that didn't start cleanly.

**Fix**:

1. Clear the `npx` cache: `npx clear-npx-cache`.
2. Turn the MCP server off and on again in your editor settings.
3. In Cursor, open **View > Output** and select `MCP: project-*` in the dropdown to read the server's log.

## Components don't load

**Cause**: the server can't reach the registry. It fetches components from `keystoneui.io`.

**Fix**:

1. Check that you have internet access.
2. Check that `https://keystoneui.io/r/registry.json` opens in a browser.
3. Restart the MCP server by turning it off and on again.
