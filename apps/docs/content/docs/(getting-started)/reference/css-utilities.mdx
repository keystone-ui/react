`@keystoneui/react/base.css` ships a few utilities that have no component. Each is a Tailwind `@utility` or an opt-in class, so it costs nothing until you use it, and each takes its colours from your theme tokens. Their names carry a `ks-` prefix so they don't collide with shadcn's utilities; [Theming](/docs/concepts/theming#why-library-names-carry-a-ks-prefix) explains the collision.

## ks-typeset

`ks-typeset` styles a block of rendered Markdown, CMS HTML or a chat reply with one class. See [Typography](/docs/components/typography#typeset) for the full reference.

```tsx
<article className="ks-typeset">{content}</article>
```

## ks-scroll-fade

`ks-scroll-fade` fades a scroll container's edges only where there is more to scroll: no fade at the top until you scroll down, and none at the bottom once you reach it. Use `ks-scroll-fade` for vertical containers and `ks-scroll-fade-x` for horizontal ones.

```tsx
<div className="ks-scroll-fade h-80 overflow-y-auto">{messages}</div>
<div className="ks-scroll-fade-x flex overflow-x-auto">{chips}</div>
```

Set `--ks-scroll-fade-size` to change the depth of each fade (default `1.5rem`). Inside a [Reel](/docs/components/reel), set `--ks-reel-fade-size` on the Reel or an ancestor instead: Reel sets `--ks-scroll-fade-size` on its own viewport.

The fade is a scroll-driven animation on a mask, so there's no scroll listener and no overlay element to click through. Browsers without scroll-driven animations show no fade and still scroll.

The horizontal fade follows the nearest `dir="ltr"` or `dir="rtl"` on the scroller or an ancestor. A CSS direction or `dir="auto"` inherits the fade setting from that boundary. With neither boundary, the fade defaults to left-to-right. Explicit left-to-right rows and the default gradient render as before, and the vertical fade is unchanged. For a row of controls that also needs arrows and keeps the focused and current items clear of the fade, use [Reel](/docs/components/reel), which is built on this utility.

## ks-shimmer

`ks-shimmer` runs a light sweep across text, for live status such as "Thinking…", a running tool or a job in progress.

```tsx
<span className="ks-shimmer text-sm">Thinking…</span>
```

The text is readable at every frame: the sweep runs between `--muted-foreground` and `--foreground`. Its period derives from `--duration-slow`, so `prefers-reduced-motion` freezes it.

## ks-scrollbar

`ks-scrollbar` is a thin, token-coloured scrollbar skin, and it's opt-in. Add the class to `<html>` to skin the page scrollbar and every nested scroll container, or to a single scroll container to skin only that one.

```tsx
<html className="ks-scrollbar">
```

`no-scrollbar` still hides the bar on any element that opts out.
