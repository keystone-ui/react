Keystone UI is a React 19 component library with 50+ accessible components, built on [Base UI](https://base-ui.com) primitives and styled with Tailwind CSS v4. You install it as an npm package or copy components into your project through a shadcn-compatible registry, and you own the theme in your own CSS. [Architecture](/docs/concepts/architecture) explains how the pieces fit.

## Start from your task

Pick the page for what you want to do:

- **Install it**: [Install Keystone UI](/docs/installation) in a Next.js or Vite app, or [install from the registry](/docs/guides/install-from-the-registry) with the shadcn CLI.
- **Theme it**: [customize the theme](/docs/guides/customize-the-theme), [enable dark mode](/docs/guides/enable-dark-mode) or [publish a theme](/docs/guides/publish-a-theme).
- **Use shadcn components alongside it**: [add shadcn components](/docs/guides/add-shadcn-components) without overwriting Keystone UI's files.
- **Upgrade it**: [upgrade to 1.0](/docs/guides/upgrade-to-1-0) from any beta.
- **Use it with AI agents**: [choose an integration](/docs/agents/choose-an-integration), then [set up the MCP server](/docs/agents/mcp-server) or another option.

## Browse by type

The docs are split by what you need from a page:

- **Guides** walk you through a task, such as [enabling dark mode](/docs/guides/enable-dark-mode) or [setting up right-to-left layouts](/docs/guides/set-up-right-to-left).
- **Concepts** explain why Keystone UI works the way it does, such as [Theming](/docs/concepts/theming) and [Keystone UI and shadcn](/docs/concepts/keystone-and-shadcn).
- **Reference** lists the facts: [theme tokens](/docs/reference/theme-tokens), [colours](/docs/reference/colors), [base.css](/docs/reference/base-css) and [CSS utilities](/docs/reference/css-utilities).
- **Components** document each component's props and examples, starting with [Button](/docs/components/button).
- **Blocks** are full-page compositions you install as a unit, such as [Sign in](/docs/blocks/signin-01).
