`@keystoneui/react/base.css` ships a few utilities that have no component.
Each is a Tailwind `@utility` or an opt-in class, so it costs nothing until you
use it, and each takes its colours from your theme tokens.

## ks-typeset

Styles a block of rendered markdown, CMS HTML or a chat reply with one class.
See [Typography](/docs/components/typography#typeset) for the full reference.

```tsx
<article className="ks-typeset">{content}</article>
```

## ks-scroll-fade

Fades a scroll container's edges only where there is more to scroll: no fade
at the top until you scroll down, none at the bottom once you reach it. Use
`ks-scroll-fade` for vertical containers and `ks-scroll-fade-x` for horizontal ones.

```tsx
<div className="ks-scroll-fade h-80 overflow-y-auto">{messages}</div>
<div className="ks-scroll-fade-x flex overflow-x-auto">{chips}</div>
```

Set `--ks-scroll-fade-size` to change the depth of each fade (default `1.5rem`).

It is a scroll-driven animation reading a mask, so there is no scroll listener
and no overlay element to click through. Browsers without scroll-driven
animations show no fade and still scroll.

## ks-shimmer

A light sweep across text, for live status — "Thinking…", a running tool, a
job in progress.

```tsx
<span className="ks-shimmer text-sm">Thinking…</span>
```

The text is readable at every frame: the sweep runs between
`--muted-foreground` and `--foreground`. Its period derives from
`--duration-slow`, so `prefers-reduced-motion` freezes it.

## ks-scrollbar

A thin, token-coloured scrollbar. Add it to `<html>` to skin every scrollbar, or
to a single scroll container.

```tsx
<html className="ks-scrollbar">
```
