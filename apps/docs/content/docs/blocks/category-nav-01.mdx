## Features

- Real links: each category is an `<a href>` styled with `buttonVariants`, so it is announced as a link, not a button. The current one carries `aria-current="page"`.
- One line that scrolls sideways when it does not fit, inside a [Reel](/docs/components/reel): faded edges where there is more, arrows for mouse and trackpad users, and the current link scrolled into view on load.
- Centered when everything fits (`mx-auto w-max` on the list).
- Takes `items`, `currentHref` and a `label` for the `<nav>`. Swap the `<a>` for your router's link component if it renders an `<a>`.
- The current link's `secondary` fill is faint on a `bg-muted` surface; on one, use the `default` variant for the current link instead.

## Filtering in place

When the bar filters a list on the same page instead of opening a category page, it's [FilterChips](/docs/components/filter-chips), not links. Here FilterChips are restyled through `FilterChip`'s `className` state function to match the bar, inside the same Reel.
