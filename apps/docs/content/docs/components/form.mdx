## Form submission

`Form` is a real `<form>` element, so it takes `onSubmit` and any standard form attribute. Pressing Enter in a nested input submits the form with no extra wiring. Call `preventDefault()` in the handler to submit with JavaScript:

```tsx
<Form
  onSubmit={(e) => {
    e.preventDefault();
    // handle submit
  }}
>
  {/* fields */}
  <Button type="submit">Save</Button>
</Form>
```

## FieldGroup without a form

`FieldGroup` renders a `<div>` with the same spacing as `Form`, without the `<form>` semantics. Use it for a group of fields inside an existing `<form>`, or for a settings panel that doesn't submit. This form holds 2 groups:

```tsx
<form onSubmit={handleSubmit}>
  <FieldGroup>
    {/* fields */}
  </FieldGroup>
  <FieldGroup>
    {/* a second group */}
  </FieldGroup>
  <Button type="submit">Save</Button>
</form>
```

## RTL

Keystone UI's own spacing doesn't mirror in right-to-left layouts yet. [Right-to-left support](/docs/concepts/rtl) lists what works and how to set it up.

## API reference

### Form

Renders a `<form>` element with consistent vertical spacing between children. It takes every `FormHTMLAttributes<HTMLFormElement>` prop.

| Prop        | Type                                   | Default | Description                                              |
| ----------- | -------------------------------------- | ------- | -------------------------------------------------------- |
| `onSubmit`  | `FormEventHandler<HTMLFormElement>`    | -       | Submission handler. Call `event.preventDefault()` first. |
| `className` | `string`                               | -       | Additional CSS classes.                                  |
| `children`  | `ReactNode`                            | -       | Form fields and controls.                                |

### FieldGroup

A layout-only `<div>` with the same spacing as `Form` and no form semantics. Use it inside an existing `<form>`, or for groups of fields that don't submit.

| Prop        | Type                            | Default | Description             |
| ----------- | ------------------------------- | ------- | ----------------------- |
| `className` | `string`                        | -       | Additional CSS classes. |
| `children`  | `ReactNode`                     | -       | Grouped fields.         |

It also takes every `HTMLAttributes<HTMLDivElement>` prop.

### Label

Renders an accessible `<label>` element. See [Label](/docs/components/label) for the full API.

| Prop        | Type        | Default | Description                                                            |
| ----------- | ----------- | ------- | ---------------------------------------------------------------------- |
| `htmlFor`   | `string`    | -       | ID of the associated control. Required for accessibility.              |
| `className` | `string`    | -       | Additional CSS classes.                                                |
| `children`  | `ReactNode` | -       | Label text.                                                            |

### Description

Renders muted helper text for form fields.

| Prop        | Type        | Default | Description             |
| ----------- | ----------- | ------- | ----------------------- |
| `className` | `string`    | -       | Additional CSS classes. |
| `children`  | `ReactNode` | -       | Helper text.            |

### ErrorMessage

Renders validation error text in the destructive color. Pair it with `aria-invalid` on the control.

| Prop        | Type        | Default | Description             |
| ----------- | ----------- | ------- | ----------------------- |
| `className` | `string`    | -       | Additional CSS classes. |
| `children`  | `ReactNode` | -       | Error message text.     |
