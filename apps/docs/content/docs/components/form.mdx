## Submission

`Form` is a real `<form>` element, so it accepts `onSubmit` and any standard form attribute. Nested inputs submit on Enter without extra wiring.

```tsx
<Form
  onSubmit={(e) => {
    e.preventDefault();
    // handle submit
  }}
>
  {/* fields */}
  <Button type="submit">Save</Button>
</Form>
```

## FieldGroup

When you need the same vertical layout but not the `<form>` semantics — for example a group of fields nested inside an existing `<form>`, or a non-submittable settings panel — use `FieldGroup`. It renders a `<div>` with the same spacing as `Form`.

```tsx
<form onSubmit={handleSubmit}>
  <FieldGroup>
    {/* fields */}
  </FieldGroup>
  <FieldGroup>
    {/* a second group */}
  </FieldGroup>
  <Button type="submit">Save</Button>
</form>
```

## API Reference

### Form

Renders a `<form>` element with consistent vertical spacing between children. Accepts all `FormHTMLAttributes<HTMLFormElement>`.

| Prop        | Type                                   | Default | Description                                              |
| ----------- | -------------------------------------- | ------- | -------------------------------------------------------- |
| `onSubmit`  | `FormEventHandler<HTMLFormElement>`    | -       | Submission handler. Call `event.preventDefault()` first. |
| `className` | `string`                               | -       | Additional CSS classes.                                  |
| `children`  | `ReactNode`                            | -       | Form fields and controls.                                |

### FieldGroup

Layout-only `<div>` wrapper that provides the same spacing as `Form` without form semantics. Use inside an existing `<form>`, or for groups of fields that don't submit.

| Prop        | Type                            | Default | Description             |
| ----------- | ------------------------------- | ------- | ----------------------- |
| `className` | `string`                        | -       | Additional CSS classes. |
| `children`  | `ReactNode`                     | -       | Grouped fields.         |

Also accepts all `HTMLAttributes<HTMLDivElement>`.

### Label

Renders an accessible `<label>` element. See [Label](/docs/components/label) for the full API.

| Prop        | Type        | Default | Description                                                            |
| ----------- | ----------- | ------- | ---------------------------------------------------------------------- |
| `htmlFor`   | `string`    | -       | ID of the associated control. Required for accessibility.              |
| `className` | `string`    | -       | Additional CSS classes.                                                |
| `children`  | `ReactNode` | -       | Label text.                                                            |

### Description

Renders muted helper text for form fields.

| Prop        | Type        | Default | Description             |
| ----------- | ----------- | ------- | ----------------------- |
| `className` | `string`    | -       | Additional CSS classes. |
| `children`  | `ReactNode` | -       | Helper text.            |

### ErrorMessage

Renders destructive-colored validation error text. Pair with `aria-invalid` on the control.

| Prop        | Type        | Default | Description             |
| ----------- | ----------- | ------- | ----------------------- |
| `className` | `string`    | -       | Additional CSS classes. |
| `children`  | `ReactNode` | -       | Error message text.     |
