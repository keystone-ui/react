### Floating

Pass `variant="floating"` on `DrawerContent` to detach a side drawer from the viewport edge on `md+` breakpoints. The drawer gets a small inset on the outer side + top + bottom, all four corners rounded, a soft shadow, and a slightly wider default — making it feel like a layer above the page rather than part of the chrome.

Use this for inspector / detail panels where the user benefits from glancing back at the underlying list (e.g. clicking a row to inspect it). For forms or focus-heavy dialogs, prefer the [Responsive](#responsive) Modal+Drawer pattern instead.

The variant has no effect on `top` / `bottom` directions or below the `md` breakpoint — those always render flush.

<ComponentPreview name="drawer-floating" />


### Scrollable

`DrawerContent` scrolls its own content, so long forms and copy stay reachable
instead of being clipped at the drawer's max height.

Wrap the middle region in `DrawerBody` when `DrawerHeader` and `DrawerFooter`
should stay pinned while only the body scrolls. `DrawerBody` ships horizontal
padding only — add `py-*` if it has no header or footer to sit against.

## API Reference

### Drawer

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | - | Controlled open state |
| `defaultOpen` | `boolean` | `false` | Open state for the uncontrolled case |
| `onOpenChange` | `(open: boolean) => void` | - | Callback when open state changes |
| `swipeDirection` | `"up" \| "right" \| "down" \| "left"` | `"down"` | The edge the drawer slides from, and the direction that swipes to dismiss |
| `snapPoints` | `(string \| number)[]` | - | Heights the drawer settles at when dragged |
| `modal` | `boolean \| "trap-focus"` | `true` | Whether the drawer blocks interaction with the page behind it |

### DrawerContent

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"flush" \| "floating"` | `"flush"` | Visual style for `left` / `right` drawers at `md+`. `floating` detaches from the edge with a gap, full radius, and shadow. No effect on `top` / `bottom` or below `md`. |
| `className` | `string` | - | Additional CSS classes |

### DrawerBody

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | - | Additional CSS classes. Ships `px-4` only — add `py-*` for a body with no header or footer beside it. |
