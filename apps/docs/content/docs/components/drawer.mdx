## Usage

Import the parts from the `drawer` subpath.

```tsx
import {
  Drawer,
  DrawerTrigger,
  DrawerClose,
  DrawerContent,
  DrawerHeader,
  DrawerBody,
  DrawerTitle,
  DrawerDescription,
  DrawerFooter,
} from "@keystoneui/react/drawer";
```

## Composition

`DrawerContent` holds a header, a scrolling body and a footer.

```text
Drawer
├── DrawerTrigger
└── DrawerContent
    ├── DrawerHeader
    │   ├── DrawerTitle
    │   └── DrawerDescription
    ├── DrawerBody
    └── DrawerFooter
        └── DrawerClose
```

A Drawer sits below Modal and every popup, so a Modal opened from a drawer covers it. [Popup layering and modality](/docs/concepts/popup-layering) explains the scale and what the `modal` prop does to the page behind.

### Floating

Pass `variant="floating"` on `DrawerContent` to detach a side drawer from the viewport edge on `md+` breakpoints. The drawer gets a small inset on its outer side, top and bottom, all 4 corners rounded, a soft shadow and a slightly wider default width. It reads as a layer above the page rather than part of the chrome.

Use it for inspector and detail panels, where people glance back at the list behind it, such as after clicking a row to inspect it. For forms or focus-heavy dialogs, use the [Responsive](#responsive) Modal and Drawer pattern instead.

The variant has no effect on `top` and `bottom` drawers or below the `md` breakpoint, where drawers always render flush.

<ComponentPreview name="drawer-floating" />

### Scrollable

`DrawerContent` scrolls its own content, so long forms and copy stay reachable
instead of being clipped at the drawer's max height.

Wrap the middle region in `DrawerBody` when `DrawerHeader` and `DrawerFooter`
should stay pinned while only the body scrolls. `DrawerBody` has horizontal
padding only, so add `py-*` if it has no header or footer to sit against.

<ComponentPreview name="drawer-scrollable" />

### Nested

A `Drawer` rendered inside another drawer's `DrawerContent` nests. While it is open, the bottom drawer behind it steps back: it gets 5% narrower and peeks out above the front drawer at its height. It eases back into place as you swipe the front drawer down.

### Responsive

Combine Modal and Drawer for a responsive dialog. On desktop it renders as a centered Modal, and on mobile it slides up as a Drawer. The example uses the `useMediaQuery` hook to detect the viewport width.

## API reference

### Drawer

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | - | Controlled open state |
| `defaultOpen` | `boolean` | `false` | Open state for the uncontrolled case |
| `onOpenChange` | `(open: boolean) => void` | - | Callback when open state changes |
| `swipeDirection` | `"up" \| "right" \| "down" \| "left"` | `"down"` | The edge the drawer slides from, and the direction that swipes to dismiss |
| `snapPoints` | `(string \| number)[]` | - | Heights the drawer settles at when dragged |
| `modal` | `boolean \| "trap-focus"` | `true` | `true` traps keyboard focus and locks document scrolling. `false` disables both. `"trap-focus"` keeps keyboard focus inside without locking document scrolling. The full-screen Drawer viewport can still intercept outside clicks. |

### DrawerContent

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"flush" \| "floating"` | `"flush"` | Visual style for `left` / `right` drawers at `md+`. `floating` detaches from the edge with a gap, full radius, and shadow. No effect on `top` / `bottom` or below `md`. |
| `overlayClassName` | `string` | - | Classes merged onto the built-in overlay; yours win over the defaults (`bg-black/20` lightens it, `hidden` removes it). Hiding the backdrop is visual only. By default, the page behind is inert and scroll-locked. On the root, `modal={false}` turns off the focus trap and document scroll lock. `modal="trap-focus"` releases the scroll lock and keeps keyboard focus inside. The full-screen Drawer viewport can still intercept outside clicks. |
| `className` | `string` | - | Additional CSS classes |

### DrawerBody

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | - | Additional CSS classes. Ships `px-4` only; add `py-*` for a body with no header or footer beside it. |
