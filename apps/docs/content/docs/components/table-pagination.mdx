## Usage

```tsx
import {
  TablePagination,
  TablePaginationButtons,
  TablePaginationControls,
  TablePaginationInfo,
  TablePaginationPageSize,
  TablePaginationStatus,
} from "@keystoneui/react/table-pagination";
```

### TablePagination or Pagination

`TablePagination` is deliberately separate from [`Pagination`](/docs/components/pagination). That component is a list of page *links* (`nav > ul > li > a`, with `aria-current="page"`), which fits when every page has its own URL. A data-table footer is a toolbar over an opaque page index: no per-page URLs, `aria-live` instead of `aria-current`, and a dependency on `Select` and `Label`. Merging the two would pull Base UI's Select into every bundle that only wanted page links.

### Page index and page size

`pageIndex` is **0-based**, and the status line renders it 1-based. `pageCount` is clamped to a minimum of 1 for display, so an empty result set reads "Page 1 of 1" rather than "Page 1 of 0".

When the page size changes, reset the page index, because page 3 of a 10-per-page list doesn't exist at 50 per page:

```tsx
onPageSizeChange={(size) => {
  setPageSize(size);
  setPageIndex(0);
}}
```

### Layout at each width

`TablePaginationInfo` shows at every width. Below the `lg` breakpoint it takes its own row above the controls, so the count reads on one line instead of being squeezed beside the buttons. An empty slot takes no room, so a footer without one stays a single row. `TablePaginationPageSize` and the first and last buttons are hidden below `lg`, so the controls fit one row on a phone.

### Accessibility

Paging swaps the table's contents with no other visible confirmation, so without an announcement a screen reader says **nothing at all** after a press on the next-page button. `TablePaginationStatus` and `TablePaginationInfo` are both `aria-live="polite"` for that reason.

Every navigation button carries an explicit `aria-label`, such as "Go to first page", because each one is icon-only.

`TablePaginationPageSize` wires its `Label` to the select trigger with a generated id. Without that, the control announces only its current value, with no hint of what the number means.

## Composition

```text
TablePagination
├── TablePaginationInfo
└── TablePaginationControls
    ├── TablePaginationPageSize
    ├── TablePaginationStatus
    └── TablePaginationButtons
```

Give `TablePagination` the props and it renders that composition for you. Pass `children` and it renders exactly what you give it instead, the same pattern as [`Progress`](/docs/components/progress).

`TablePaginationControls` is the group the last three parts sit in. It's full width below `lg`, so the controls fill the row under the info slot, and intrinsic width above it, so they sit at the end. It's exported because `children` replaces the default composition entirely, and without it the only way to reproduce that grouping is to copy its classes.

## API reference

### TablePagination

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `pageIndex` | `number` | *required* | 0-based current page |
| `pageCount` | `number` | *required* | Total pages |
| `pageSize` | `number` | - | Omit to hide the page-size control |
| `pageSizeOptions` | `readonly number[]` | `[10, 20, 30, 50]` | Page-size choices |
| `selectedCount` | `number` | - | Omit to hide the selection line |
| `totalCount` | `number` | - | Rows in the whole result set |
| `showEdgeButtons` | `boolean` | `true` | Render the first/last buttons |
| `onPageIndexChange` | `(index: number) => void` | - | Called with the target page |
| `onPageSizeChange` | `(size: number) => void` | - | Called with a `number`, not a string |
| `children` | `ReactNode` | - | Replaces the default composition |

### TablePaginationControls

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | - | The controls to group |

### TablePaginationButtons

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `pageIndex` | `number` | *required* | 0-based current page |
| `pageCount` | `number` | *required* | Total pages |
| `showEdgeButtons` | `boolean` | `true` | Render the first/last buttons |
| `onPageIndexChange` | `(index: number) => void` | - | Called with the target page |

### TablePaginationStatus

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `pageIndex` | `number` | *required* | 0-based current page |
| `pageCount` | `number` | *required* | Total pages, clamped to ≥ 1 for display |
| `children` | `ReactNode` | - | Replaces the default "Page N of M" |

### TablePaginationPageSize

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `number` | - | Current page size |
| `options` | `readonly number[]` | `[10, 20, 30, 50]` | Page-size choices |
| `label` | `string` | `"Rows per page"` | Label text |
| `onValueChange` | `(size: number) => void` | - | Called with a `number` |

### TablePaginationInfo

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `selectedCount` | `number` | - | Rows selected. Omit to render nothing. |
| `totalCount` | `number` | - | Rows in the whole result set |
| `children` | `ReactNode` | - | Replaces the default sentence |
