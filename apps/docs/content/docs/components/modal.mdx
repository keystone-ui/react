## Usage

```tsx
import {
  Modal,
  ModalTrigger,
  ModalContent,
  ModalHeader,
  ModalTitle,
  ModalDescription,
  ModalFooter,
  ModalClose,
} from "@keystoneui/react/modal";
```

## Composition

```text
Modal
├── ModalTrigger
└── ModalContent
    ├── ModalHeader
    │   ├── ModalTitle
    │   └── ModalDescription
    └── ModalFooter
        └── ModalClose
```

### Overlay

`overlayClassName` restyles the built-in overlay for one modal. Your classes win over the default tint, so `bg-black/20` lightens it and `hidden` removes it.

<ComponentPreview name="modal-overlay" />

Hiding the backdrop is visual only. By default, the page behind is inert and scroll-locked. On the root, `modal={false}` turns off the focus trap and document scroll lock. `modal="trap-focus"` releases the scroll lock and keeps keyboard focus inside. For clicks to reach the page behind a hidden backdrop, also use `scrollBehavior="inside"`. [Popup layering](/docs/concepts/popup-layering) explains each `modal` setting.

## API reference

### Modal

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | - | Controlled open state |
| `onOpenChange` | `(open: boolean) => void` | - | Callback when open state changes |
| `defaultOpen` | `boolean` | `false` | Initial open state (uncontrolled) |

### ModalContent

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `"sm" \| "default" \| "lg" \| "xl" \| "full"` | `"default"` | Modal width |
| `overlayClassName` | `string` | - | Classes merged onto the built-in overlay; yours win over the defaults. Hiding the backdrop is visual only. By default, the page behind is inert and scroll-locked. On the root, `modal={false}` turns off the focus trap and document scroll lock. `modal="trap-focus"` releases the scroll lock and keeps keyboard focus inside. For clicks to reach the page behind a hidden backdrop, also use `scrollBehavior="inside"`. |
| `className` | `string` | - | Additional CSS classes |
