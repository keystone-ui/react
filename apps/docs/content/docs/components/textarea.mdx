## Import

```tsx
import { Textarea } from "@keystoneui/react/textarea";
```

## Usage

The textarea auto-sizes to fit its content using `field-sizing-content`. Resizing is disabled by default.

## API Reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | - | Additional CSS classes |
| `disabled` | `boolean` | `false` | Disables the textarea |
| `placeholder` | `string` | - | Placeholder text |
| `maxLength` | `number` | - | Maximum character length |

The Textarea auto-sizes to fit content. Pass `rows` if you need a fixed initial height. It forwards all standard HTML `<textarea>` props.
