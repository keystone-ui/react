## Usage

```tsx
import { Textarea } from "@keystoneui/react/textarea";
```

Render it with a placeholder:

```tsx
<Textarea placeholder="Type your message here." />
```

The textarea grows to fit its content with `field-sizing-content`. Manual resizing is off by default.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | - | Additional CSS classes |
| `disabled` | `boolean` | `false` | Disables the textarea |
| `placeholder` | `string` | - | Placeholder text |
| `maxLength` | `number` | - | Maximum character length |

The textarea grows to fit its content. Pass `rows` for a fixed initial height. It forwards every standard HTML `<textarea>` prop.
