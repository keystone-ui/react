### Record

`orientation="stacked"` puts the term above the details — the shape a read-only detail page wants, where the default row layout right-aligns each value against its label and reads as a summary.

Columns are layout, so they go in `className`. `grid` supersedes the component's default `flex`, and the stacked row gap survives alongside your own `gap-x-*`:

```tsx
<DescriptionList
  className="grid grid-cols-1 gap-x-8 sm:grid-cols-2"
  orientation="stacked"
>
```

## API Reference

### DescriptionList

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `orientation` | `"row" \| "stacked"` | `"row"` | `row` puts term and details on one line with the value right-aligned; `stacked` puts the term above, left-aligned, and spaces the rows. Multi-column layouts go in `className` |
| `size` | `"default" \| "sm"` | `"default"` | The size variant |
| `variant` | `"default" \| "card"` | `"default"` | The visual variant |
| `className` | `string` | - | Additional CSS classes |
