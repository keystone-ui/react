## Usage

```tsx
import {
  Slider,
  SliderControl,
  SliderTrack,
  SliderIndicator,
  SliderThumb,
  SliderValue,
} from "@keystoneui/react/slider";
```

Nest the track, indicator and thumb inside `SliderControl`:

```tsx
<Slider className="max-w-sm" defaultValue={25}>
  <SliderControl>
    <SliderTrack>
      <SliderIndicator />
      <SliderThumb aria-label="Volume" />
    </SliderTrack>
  </SliderControl>
</Slider>
```

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `defaultValue` | `number \| number[]` | - | Default value(s) |
| `value` | `number \| number[]` | - | Controlled value(s) |
| `onValueChange` | `(value: number[]) => void` | - | Callback when value changes |
| `min` | `number` | `0` | Minimum value |
| `max` | `number` | `100` | Maximum value |
| `step` | `number` | `1` | Step increment |
| `disabled` | `boolean` | `false` | Whether the slider is disabled |
