## Usage

Import Progress from its subpath.

```tsx
import { Progress } from "@keystoneui/react/progress";
```

Pass `value` to set how much of the bar is filled.

```tsx
<Progress className="max-w-md" value={60} />
```

## Composition

Progress has a label, a value and a track that holds the indicator.

```text
Progress
├── ProgressLabel
├── ProgressValue
└── ProgressTrack
    └── ProgressIndicator
```

With no children, `Progress` renders `ProgressTrack` and `ProgressIndicator`
for you. When you pass children to add a label or value, you render the whole
tree yourself, track included.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `number` | `0` | Current progress value (0-100) |
| `max` | `number` | `100` | Maximum progress value |
| `color` | `"default" \| "success" \| "warning" \| "destructive"` | `"default"` | Color of the indicator |
| `className` | `string` | - | Additional CSS classes |
