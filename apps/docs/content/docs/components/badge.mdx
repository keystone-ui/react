## Usage

Import Badge from its subpath.

```tsx
import { Badge } from "@keystoneui/react/badge";
```

Put the label text inside it.

```tsx
<Badge>Badge</Badge>
```

## Examples

### Variants

Set `variant` to pick one of 10 styles.

<ComponentPreview name="badge-variants" />

| Variant | Use case |
| --- | --- |
| `default` | Primary emphasis badges |
| `secondary` | Subtle secondary labels |
| `success` | Positive status, such as completed or active |
| `warning` | Needs attention, such as pending or expiring |
| `info` | Neutral, informational status |
| `error` | Failed or blocked status |
| `destructive` | Deprecated: use `error`, which it draws |
| `outline` | Bordered minimal badges |
| `ghost` | Low-emphasis hover-revealed badges |
| `link` | Underlined text-style badges |

### Status

The 4 status tones, `success`, `warning`, `info` and `error`, each come in 2 appearances. Solid is the default. `appearance="soft"` tints the fill with the tone's color and adds a border in the same color, for a quieter badge in dense lists and tables. A status Badge rendered as a link underlines on hover and keeps its fill.

<ComponentPreview name="badge-status" />

This snippet renders a solid `success` badge and a soft `error` badge with an icon.

```tsx
<Badge variant="success">Paid</Badge>
<Badge variant="error" appearance="soft">
  <CircleXIcon data-icon="inline-start" />
  Failed
</Badge>
```

`appearance` only affects the status tones; `default`, `secondary`, `outline`, `ghost` and `link` ignore it.

The red fill, text and soft border use Tailwind's red palette. A customized `--destructive` still supplies the focus-ring color.

### Destructive (deprecated)

`variant="destructive"` is a deprecated alias of `error` and draws exactly what `error` draws. A Badge with `variant="destructive"` now draws the solid red by default. Use `appearance="soft"` for the tinted look, which now has a border, a slightly deeper red in light mode and a slightly fainter tint in dark mode. Use `variant="error"` instead: we'll remove `destructive` from Badge in a later release. Button's `destructive` variant is unchanged.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"default" \| "secondary" \| "success" \| "warning" \| "info" \| "error" \| "destructive" \| "outline" \| "ghost" \| "link"` | `"default"` | Visual style variant. `destructive` is deprecated: use `error`, which it draws. |
| `appearance` | `"solid" \| "soft"` | `"solid"` | How a status tone is filled: solid, or a soft tint with a border. Applies to `success`, `warning`, `info`, `error` and the deprecated `destructive` alias. Other variants ignore it. |
| `size` | `"default" \| "sm"` | `"default"` | Size of the badge |
| `className` | `string` | - | Additional CSS classes |
