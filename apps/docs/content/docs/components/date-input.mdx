`DateInput` uses the browser's own date field; for a styled calendar in a popup, see [Date Picker](/docs/components/date-picker).

## Usage

```tsx
import { DateInput } from "@keystoneui/react/date-input";
```

Render it with no props for an empty date field:

```tsx
<DateInput />
```
