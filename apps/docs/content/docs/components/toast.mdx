## Composition

`Toaster` is the rendering surface — mount it once at the root of your app (typically in your root layout). `toast` is an imperative API: call `toast.success(...)`, `toast.error(...)`, etc. from anywhere in your app to enqueue a toast for the mounted `Toaster` to render.

```tsx
// app/layout.tsx
<Toaster />

// anywhere else
toast.success("Saved");
toast.error("Something went wrong");
```

## API Reference

### toast()

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `message` | `string` | - | The toast message |
| `description` | `string` | - | Optional description text |
| `action` | `ToastAction` | - | Action button configuration |
| `position` | `ToastPosition` | `"bottom-right"` | Position on screen |
| `duration` | `number` | `4000` | Duration in milliseconds |

### Toaster

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `position` | `ToastPosition` | `"bottom-right"` | Default position for all toasts |
| `richColors` | `boolean` | `false` | Use semantic colors for toast types |
