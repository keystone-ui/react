## Usage

There is no `DatePicker` export. A date picker is a `Calendar` inside a `Popover`, opened by a `Button` (or an `InputGroupButton` beside a text field). Copy the example closest to what you need and own it: the trigger, the date format and whether picking closes the popup are yours to change.

```tsx
import { Button } from "@keystoneui/react/button";
import { Calendar } from "@keystoneui/react/calendar";
import {
  Popover,
  PopoverContent,
  PopoverTrigger,
} from "@keystoneui/react/popover";
import { format } from "date-fns";
import { useState } from "react";
```

```tsx
const [open, setOpen] = useState(false);
const [date, setDate] = useState<Date>();

<Popover onOpenChange={setOpen} open={open}>
  <PopoverTrigger
    render={
      <Button variant="outline">
        {date ? format(date, "PPP") : "Pick a date"}
      </Button>
    }
  />
  <PopoverContent
    align="start"
    aria-label="Choose a date"
    className="w-auto overflow-hidden p-0"
  >
    <Calendar
      mode="single"
      onSelect={(d) => {
        setDate(d);
        setOpen(false);
      }}
      selected={date}
    />
  </PopoverContent>
</Popover>
```

Install the parts with `npx shadcn@latest add https://keystoneui.io/r/popover.json https://keystoneui.io/r/calendar.json`, or install a single example below by its name (for instance `https://keystoneui.io/r/date-picker-range.json`). Install `date-fns` alongside `@keystoneui/react`.

## Composition

```text
Popover
├── PopoverTrigger (render={<Button />} or <InputGroupButton />)
└── PopoverContent
    └── Calendar (mode="single" | "range")
```

## API Reference

A date picker has no props of its own. See [Popover](/docs/components/popover#api-reference) for popup placement and [Calendar](/docs/components/calendar#api-reference) for selection modes and disabled dates.
