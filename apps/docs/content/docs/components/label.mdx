## Usage

```tsx
import { Label, Description, ErrorMessage } from "@keystoneui/react/label";
```

## Composition

`Label`, `Description` and `ErrorMessage` are siblings, not nested. Place them beside a control inside a wrapper, such as `Field` from `@keystoneui/react/field` or your own `<div>`:

```tsx
<Field>
  <Label htmlFor="email">Email</Label>
  <Input id="email" />
  <Description>We'll never share your email.</Description>
  <ErrorMessage>Invalid email address.</ErrorMessage>
</Field>
```

### Disabled

With the default rendering of `Checkbox`, `RadioGroupItem` and `Switch`, a sibling `Label` doesn't dim when the control is disabled. To dim the label, use `FieldLabel` inside `<Field data-disabled>` and pass `disabled` to the control:

```tsx
import { Checkbox } from "@keystoneui/react/checkbox";
import { Field, FieldLabel } from "@keystoneui/react/field";

<Field data-disabled orientation="horizontal">
  <Checkbox disabled id="terms" />
  <FieldLabel htmlFor="terms">Accept terms</FieldLabel>
</Field>
```

## API reference

### Label

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `htmlFor` | `string` | - | ID of the associated form control |
| `className` | `string` | - | Additional CSS classes |

### Description

Renders muted helper text below a form control.

### ErrorMessage

Renders destructive-colored error text below a form control.
