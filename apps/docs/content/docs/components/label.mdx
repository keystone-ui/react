## Composition

`Label`, `Description`, and `ErrorMessage` are siblings, not nested. Place them alongside a control inside a parent wrapper (typically `Field` from `@keystoneui/react/field`, or a custom `<div>`):

```tsx
<Field>
  <Label htmlFor="email">Email</Label>
  <Input id="email" />
  <Description>We'll never share your email.</Description>
  <ErrorMessage>Invalid email address.</ErrorMessage>
</Field>
```

## API Reference

### Label

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `htmlFor` | `string` | - | ID of the associated form control |
| `className` | `string` | - | Additional CSS classes |

### Description

Renders muted helper text below a form control.

### ErrorMessage

Renders destructive-colored error text below a form control.
