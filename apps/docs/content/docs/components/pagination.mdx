## Import

```tsx
import {
  Pagination,
  PaginationContent,
  PaginationItem,
  PaginationPrevious,
  PaginationNext,
  PaginationLink,
  PaginationEllipsis,
} from "@keystoneui/react/pagination";
```

## Usage

For the footer of a paginated data table — rows-per-page, "page N of M" and the four navigation buttons — use [`TablePagination`](/docs/components/table-pagination) instead. `Pagination` is a list of page *links* (`nav > ul > li > a`, with `aria-current="page"`); a data-table footer is a toolbar with an opaque page index and no per-page URLs.

## RTL

RTL support in Keystone UI is partial: Base UI handles keyboard navigation and popup positioning when you supply a `DirectionProvider`, but the library's own spacing is written with physical utilities and does not mirror. See [the RTL guide](/docs/rtl) for what works today.

## API Reference

### PaginationLink

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `href` | `string` | - | Page URL |
| `isActive` | `boolean` | `false` | Whether this is the current page |
| `className` | `string` | - | Additional CSS classes |
