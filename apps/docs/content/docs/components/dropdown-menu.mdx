### Checkboxes

Use checkbox items for toggling options:

<ComponentPreview name="dropdown-menu-checkboxes" />

Checkbox items **leave the menu open** when clicked, so a group of them can be
toggled in one visit — the column-visibility menu in [`tickets-01`](/docs/blocks/tickets-01)
depends on it. Pass `closeOnClick` if a single checkbox is the whole interaction.


### Radio Group

Use radio items for mutually exclusive selection:

<ComponentPreview name="dropdown-menu-radio-group" />

Radio items **close the menu** when picked, which is the opposite of the
checkbox behaviour above. Picking one *is* the interaction, so there is nothing
left in the popup to act on — and a menu that stays open keeps an inert overlay
across the page that silently swallows the next click. Pass `closeOnClick={false}`
to keep it open, for a menu that reveals more controls once a choice is made.

<Callout type="info">
  This is a deliberate deviation from Base UI, which defaults `closeOnClick` to
  `false` on both item types. Radix — and therefore shadcn — closes on select,
  so keystone's radio items behave the way a port expects.
</Callout>

## RTL

RTL support in Keystone UI is partial: Base UI handles keyboard navigation and popup positioning when you supply a `DirectionProvider`, but the library's own spacing is written with physical utilities and does not mirror. See [the RTL guide](/docs/rtl) for what works today.

## API Reference

### DropdownMenuContent

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"bottom"` | Preferred placement side |
| `align` | `"start" \| "center" \| "end"` | `"start"` | Alignment along the side axis |
| `size` | `"default" \| "compact"` | `"default"` | Item height density |
| `className` | `string` | - | Additional CSS classes |

### DropdownMenuItem

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `disabled` | `boolean` | `false` | Whether the item is disabled |
| `className` | `string` | - | Additional CSS classes |

### DropdownMenuCheckboxItem

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `checked` | `boolean` | - | Whether the item is checked |
| `onCheckedChange` | `(checked: boolean) => void` | - | Called when the checked state changes |
| `closeOnClick` | `boolean` | `false` | Whether clicking closes the menu |
| `variant` | `"indicator" \| "control"` | `"indicator"` | Check icon on the right, or a real Checkbox on the left |
| `className` | `string` | - | Additional CSS classes |

### DropdownMenuRadioItem

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | - | The value this item selects |
| `closeOnClick` | `boolean` | `true` | Whether clicking closes the menu |
| `variant` | `"indicator" \| "control"` | `"indicator"` | Check icon on the right, or a real radio control on the left |
| `className` | `string` | - | Additional CSS classes |
