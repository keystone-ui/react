## Usage

Import the parts from the `dropdown-menu` subpath.

```tsx
import {
  DropdownMenu,
  DropdownMenuTrigger,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuSeparator,
  DropdownMenuGroup,
  DropdownMenuLabel,
  DropdownMenuShortcut,
  DropdownMenuCheckboxItem,
  DropdownMenuRadioGroup,
  DropdownMenuRadioItem,
  DropdownMenuSub,
  DropdownMenuSubTrigger,
  DropdownMenuSubContent,
} from "@keystoneui/react/dropdown-menu";
```

## Composition

`DropdownMenuContent` holds groups of items, separators and submenus.

```text
DropdownMenu
├── DropdownMenuTrigger
└── DropdownMenuContent
    ├── DropdownMenuGroup
    │   ├── DropdownMenuLabel
    │   ├── DropdownMenuItem
    │   │   └── DropdownMenuShortcut
    │   ├── DropdownMenuCheckboxItem
    │   └── DropdownMenuRadioGroup
    │       └── DropdownMenuRadioItem
    ├── DropdownMenuSeparator
    └── DropdownMenuSub
        ├── DropdownMenuSubTrigger
        └── DropdownMenuSubContent
```

**Invalid nesting:** `DropdownMenuLabel` must sit inside a `DropdownMenuGroup`
or `DropdownMenuRadioGroup`. Placed directly in `DropdownMenuContent`, Base UI
throws `MenuGroupContext is missing` when the menu opens.

A menu opened from inside a Modal or Drawer appears above it. [Popup layering and modality](/docs/concepts/popup-layering) explains the scale.

### With icons

### Checkboxes

Use `DropdownMenuCheckboxItem` for options that turn on and off.

<ComponentPreview name="dropdown-menu-checkboxes" />

Checkbox items **leave the menu open** when clicked, so you can toggle a group
of them in one visit. The column-visibility menu in [`tickets-01`](/docs/blocks/tickets-01)
depends on this. Pass `closeOnClick` if a single checkbox is the whole interaction.

### Radio group

Use `DropdownMenuRadioItem` inside a `DropdownMenuRadioGroup` when only one option can be selected.

<ComponentPreview name="dropdown-menu-radio-group" />

Radio items **close the menu** when picked, the opposite of checkbox items.
Picking one *is* the interaction, so nothing is left in the popup to act on. A
menu that stays open keeps an inert overlay across the page that silently
swallows the next click. Pass `closeOnClick={false}` to keep it open, for a menu
that reveals more controls once a choice is made.

<Callout type="info">
  This is a deliberate deviation from Base UI, which defaults `closeOnClick` to
  `false` on both item types. Radix, and therefore shadcn, closes on select,
  so Keystone UI's radio items behave the way a port expects.
</Callout>

### Filter

A toolbar filter whose trigger reads `Status: Failed`, the dimension muted and then the value, and opens a radio group. A bare value is ambiguous beside another one ("Failed" next to "Deposit"). The muted unset value (`Status: All`) lets the active filters stand out. [`admin-01`](/docs/blocks/admin-01) has a full filter row built on this, with removable pills and `+ Add filter`.

## API reference

### DropdownMenuContent

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"bottom"` | Preferred placement side |
| `align` | `"start" \| "center" \| "end"` | `"start"` | Alignment along the side axis |
| `size` | `"default" \| "compact"` | `"default"` | Item height density |
| `className` | `string` | - | Additional CSS classes |

### DropdownMenuSubContent

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `side` | `"top" \| "right" \| "bottom" \| "left" \| "inline-start" \| "inline-end"` | `"right"`, `"left"` inside a right-to-left `DirectionProvider` | Preferred side of the row. Unset, it follows Base UI's `DirectionProvider`: `"left"` when its direction is `rtl`, else `"right"`. Base UI can flip the side when there is no room. Set `side="right"` to keep the former placement |
| `align` | `"start" \| "center" \| "end"` | `"start"` | Alignment along the side axis |
| `size` | `"default" \| "compact"` | `"default"` | Item height density; not inherited from the parent menu |
| `className` | `string` | - | Additional CSS classes |

### DropdownMenuItem

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `disabled` | `boolean` | `false` | Whether the item is disabled |
| `className` | `string` | - | Additional CSS classes |

### DropdownMenuCheckboxItem

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `checked` | `boolean` | - | Whether the item is checked |
| `onCheckedChange` | `(checked: boolean) => void` | - | Called when the checked state changes |
| `closeOnClick` | `boolean` | `false` | Whether clicking closes the menu |
| `variant` | `"indicator" \| "control"` | `"indicator"` | Check icon on the right, or a real Checkbox on the left |
| `className` | `string` | - | Additional CSS classes |

### DropdownMenuRadioItem

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | - | The value this item selects |
| `closeOnClick` | `boolean` | `true` | Whether clicking closes the menu |
| `variant` | `"indicator" \| "control"` | `"indicator"` | Check icon on the right, or a real radio control on the left |
| `className` | `string` | - | Additional CSS classes |
