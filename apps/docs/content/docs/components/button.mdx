```tsx

```

```tsx
<Button>Default Button</Button>
```

### Links that look like buttons

A link that should look like a button is a plain `<a>` styled with `buttonVariants`. It stays a link: screen readers announce it as a link, and Enter follows it but Space doesn't. `buttonVariants` takes the same `variant`, `size` and `fullWidth` options as `Button`. It's exported from a client module, so call it in a client component (`"use client"`), as the [As link](#as-link) demo does.

Don't render an anchor through `Button` (`nativeButton={false} render={<a href="…" />}`). Base UI gives it `role="button"`, so screen readers announce it as a button, and Space follows it.

## Examples

### Variants

Button has 6 visual variants, set with `variant`:

<ComponentPreview name="button-variants" />

| Variant | Use case |
| --- | --- |
| `default` | Primary actions, calls to action |
| `secondary` | Secondary actions alongside a primary |
| `destructive` | Delete, remove, or dangerous operations |
| `outline` | Bordered button, for example a Cancel action |
| `ghost` | Minimal emphasis, toolbar actions |
| `link` | Inline text-style links with button behavior |

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"default" \| "secondary" \| "destructive" \| "outline" \| "ghost" \| "link"` | `"default"` | Visual style variant |
| `size` | `"default" \| "xs" \| "sm" \| "lg" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg"` | `"default"` | Size of the button |
| `isLoading` | `boolean` | `false` | Shows loading spinner and disables button; the button keeps its label as its name and sets `aria-busy` |
| `disabled` | `boolean` | `false` | Disables the button |
| `fullWidth` | `boolean` | `false` | Stretch the button to the full width of its container |
| `className` | `string` | - | Additional CSS classes |
| `render` | `React.ReactElement` | - | Render as a different element (Base UI polymorphism) |
