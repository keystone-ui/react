## Usage

Import CircularProgress from its subpath.

```tsx
import { CircularProgress } from "@keystoneui/react/circular-progress";
```

Pass `value` to set how much of the ring is filled.

```tsx
<CircularProgress value={65} />
```

## Composition

CircularProgress has a track, an indicator, a value and a label.

```text
CircularProgress
├── CircularProgressTrack
├── CircularProgressIndicator
├── CircularProgressValue
└── CircularProgressLabel
```

With no children, `CircularProgress` renders the track, indicator and value.
When you pass children to add a label or drop the value, you render the whole
tree yourself.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `number` | `0` | Current progress value (0-100) |
| `max` | `number` | `100` | Maximum progress value |
| `size` | `number` | - | Diameter of the circle in pixels |
| `strokeWidth` | `number` | - | Thickness of the progress ring |
| `className` | `string` | - | Additional CSS classes |
