## Usage

Import the parts from the `alert` subpath.

```tsx
import { Alert, AlertTitle, AlertDescription, AlertAction } from "@keystoneui/react/alert";
```

## Composition

An Alert holds an optional icon, a title, a description and an optional action.

```text
Alert
├── Icon
├── AlertTitle
├── AlertDescription
└── AlertAction
```

## Examples

### Variants

Set `variant` to match the kind of message.

<ComponentPreview name="alert-variants" />

| Variant | Use case |
| --- | --- |
| `default` | General informational messages |
| `success` | Successful operations or confirmations |
| `warning` | Caution or attention needed |
| `error` | Errors or critical failures |
| `info` | Informational tips or notes |
