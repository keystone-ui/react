## Usage

Import Skeleton from its subpath.

```tsx
import { Skeleton } from "@keystoneui/react/skeleton";
```

## Composition

`SkeletonGroup` wraps any number of `Skeleton` shapes.

```text
SkeletonGroup
└── Skeleton
```

`SkeletonGroup` runs one shimmer across every `Skeleton` inside it, so a card
of placeholders animates as one surface instead of each bar on its own clock.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `animationType` | `"pulse" \| "none"` | `"pulse"` | Pulse while loading, or stay static |
| `className` | `string` | - | Additional CSS classes for sizing and shape |
