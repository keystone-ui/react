## Usage

```tsx
import {
  Select,
  SelectTrigger,
  SelectValue,
  SelectContent,
  SelectItem,
  SelectGroup,
  SelectLabel,
  SelectSeparator,
} from "@keystoneui/react/select";
```

## Composition

```text
Select
├── SelectTrigger
│   └── SelectValue
└── SelectContent
    └── SelectGroup
        ├── SelectLabel
        ├── SelectItem
        └── SelectSeparator
```

**Invalid nesting:** `SelectLabel` must sit inside a `SelectGroup`. Placed
directly in `SelectContent`, Base UI throws `SelectGroupContext is missing`.

## Examples

### Displaying labels in the trigger

`SelectValue` renders the selected option's `value` by default, such as `"us"`.
To show the label, such as `"United States"`, pass an `items` map to `Select`
so it can resolve each value to its label:

```tsx
const countries = { us: "United States", ca: "Canada", uk: "United Kingdom" };

<Select items={countries} defaultValue="us">
  <SelectTrigger>
    <SelectValue />
  </SelectTrigger>
  <SelectContent>
    {Object.entries(countries).map(([value, label]) => (
      <SelectItem key={value} value={value}>{label}</SelectItem>
    ))}
  </SelectContent>
</Select>
```

For a computed display, pass a render function as `SelectValue`'s child. The
[multiple selection](#multiple-selection) example uses this pattern:

```tsx
<SelectValue>{(value) => labels[value] ?? "Select…"}</SelectValue>
```

### Responsive

A Select from 768px up and a Drawer with a list of options on phones, sharing one value:

<ComponentPreview name="select-responsive" />

`useMediaQuery` can't see a viewport on the server, so the server HTML is the phone branch. A desktop visitor sees the phone trigger until hydration, then the Select's. Both triggers share one look, so the swap moves nothing and hydration doesn't warn. [Server rendering](/docs/concepts/server-rendering) explains why a media query result can't render on the server.

Each branch keeps its own open state. If the viewport crosses the breakpoint while the Drawer or the Select is open, it closes with its branch: the value is kept and the page isn't left scroll-locked.

## API reference

### Select

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | - | Controlled selected value |
| `defaultValue` | `string` | - | Default selected value (uncontrolled) |
| `onValueChange` | `(value: string) => void` | - | Callback when value changes |
| `disabled` | `boolean` | `false` | Disables the select |
| `multiple` | `boolean` | `false` | Allow multiple selections |
| `items` | `Record<string, ReactNode>` \| `Array<{ value, label }>` | - | Value → label mapping for `SelectValue` to render in the trigger |

### SelectTrigger

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `"default" \| "sm"` | `"default"` | Size variant |
| `className` | `string` | - | Additional CSS classes |

### SelectItem

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | - | Item value (required) |
| `disabled` | `boolean` | `false` | Disables the item |
