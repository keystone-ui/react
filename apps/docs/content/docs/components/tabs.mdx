## Morphing

Collapse inactive triggers to icon-only and reveal the label only on the active
tab. Set `morphing` on `TabsList` and wrap each trigger's text in
`<TabsTriggerLabel>`. Every trigger should include an icon so the collapsed
state still reads. The pill and label morph together via a single spring, and
rapid clicks carry velocity instead of restarting.

<ComponentPreview name="tabs-morphing" />

### Morphing with Line Variant

Combine `morphing` with `variant="line"` for an underline-style morph. The 2px
bar stretches and slides to match the active trigger's expanded width.

## API Reference

### Tabs

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `defaultValue` | `string` | - | Default active tab value |
| `value` | `string` | - | Controlled active tab value |
| `onValueChange` | `(value: string) => void` | - | Callback when active tab changes |

### TabsList

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"default" \| "line"` | `"default"` | Visual style variant |
| `shape` | `"rounded" \| "pill"` | `"rounded"` | Trigger corner radius |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Tab list orientation |
| `scrollable` | `boolean` | `false` | Enable horizontal scroll with arrow buttons and gradient fades |
| `morphing` | `boolean` | `false` | Collapse inactive triggers to icon-only; only the active trigger shows its `TabsTriggerLabel` |

### TabsTrigger

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | - | Unique tab identifier |
| `disabled` | `boolean` | `false` | Whether the tab is disabled |

### TabsTriggerLabel

Wraps a tab's text label so it can collapse to width 0 in `morphing` mode.
Outside morphing mode it behaves like a plain `<span>`.
