## Usage

```tsx
import {
  Tabs,
  TabsList,
  TabsTrigger,
  TabsTriggerLabel,
  TabsContent,
} from "@keystoneui/react/tabs";
```

```tsx
<Tabs className="w-[400px]" defaultValue="overview">
  <TabsList>
    <TabsTrigger value="overview">Overview</TabsTrigger>
    <TabsTrigger value="analytics">Analytics</TabsTrigger>
    <TabsTrigger value="reports">Reports</TabsTrigger>
    <TabsTrigger value="settings">Settings</TabsTrigger>
  </TabsList>
  <TabsContent value="overview">
    <p className="pt-2 text-muted-foreground text-sm">
      View your key metrics and recent project activity. Track progress
      across all your active projects.
    </p>
  </TabsContent>
  <TabsContent value="analytics">
    <p className="pt-2 text-muted-foreground text-sm">
      Track performance and user engagement metrics. Monitor trends and
      identify growth opportunities.
    </p>
  </TabsContent>
  <TabsContent value="reports">
    <p className="pt-2 text-muted-foreground text-sm">
      Generate and download your detailed reports. Export data in multiple
      formats for analysis.
    </p>
  </TabsContent>
  <TabsContent value="settings">
    <p className="pt-2 text-muted-foreground text-sm">
      Manage your account preferences and options. Customize your experience
      to fit your needs.
    </p>
  </TabsContent>
</Tabs>
```

### Morphing

Collapse inactive triggers to icon-only and reveal the label only on the active
tab. Set `morphing` on `TabsList` and wrap each trigger's text in
`<TabsTriggerLabel>`. Every trigger should include an icon so the collapsed
state still reads. The pill and the label width use the same spring settings. A
rapid selection starts the next glide from the pill's current box, clipped to
the span of the tabs after the selection commits. If the boxes no longer
overlap, the pill appears on the selected tab. The filled pill keeps its round
caps.

On each frame the controller can measure a connected list with positive width
and height, the pill stays within the outer edges of the tabs taking part in the
glide, to within one CSS pixel. These include the tabs involved in earlier
selections during the same glide. This holds under positive, axis-aligned
ancestor scales. The pill's inset and minimum-size rules must allow it to fit.
Changes after the controller's frame pass, rotations, skews, perspective,
reflections, transforms between the list and its tabs, and CSS animation or
transitions on pill geometry fall outside it. Tabs moved between lists by DOM
manipulation, a tab rendered through a portal into a container that another
component removes, and glides between tabs more than about 100,000 CSS pixels
apart are also outside it.
If a participating tab is disconnected or belongs to another list when the
controller next checks, the glide ends and the pill returns to its CSS position.

### Scrollable

`scrollable` puts the list in a [Reel](/docs/components/reel). It scrolls sideways when the tabs do not fit, on desktop and touch. Each edge fades where there is more to scroll, and a bare chevron at that edge scrolls the list by 80% of its visible width. The chevrons are not buttons: they are not Tab stops and are not announced, because Tab enters the list at its roving tab stop, and the arrow keys, Home and End reach every tab with as much edge clearance as the scroll range allows. The row is hidden for five spacing units (1.25rem with the default spacing scale) under each visible chevron, so it never draws over a tab. Reel brings the active tab into view when the list gains room or the selection changes, if the Reel's last measured content width and the tab's width are positive. Focus stays where it is. In `morphing` mode, Reel uses the trigger's width at the time of the reveal; if its label grows afterwards, part of it can remain under the fade.

To choose when the arrows show or how they look, leave `scrollable` off and wrap the `TabsList` in your own Reel. Reel finds the active tab by its `aria-selected`. A tab earlier in the list that carries your own `aria-current` or `data-selected` would be brought into view instead of the active tab.

Change the fade's depth with `--ks-reel-fade-size` on `Tabs`: `className="[--ks-reel-fade-size:1rem]"`.

## RTL

RTL support in Keystone UI is partial: Base UI handles keyboard navigation and popup positioning when you supply a `DirectionProvider`, but the library's own spacing is written with physical utilities and does not mirror. See [the RTL guide](/docs/rtl) for what works today. A scrollable list's fade, arrows and paging mirror as described for Reel; put the explicit `dir` on an ancestor of the whole list, such as the `Tabs` root.

## API Reference

### Tabs

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `defaultValue` | `BaseTabs.Tab.Value` | - | Default active tab value |
| `value` | `BaseTabs.Tab.Value` | - | Controlled active tab value |
| `onValueChange` | `(value: BaseTabs.Tab.Value, eventDetails: BaseTabs.Root.ChangeEventDetails) => void` | - | Callback when active tab changes |

`BaseTabs` is Base UI's `Tabs` namespace (`import { Tabs as BaseTabs } from "@base-ui/react/tabs"`).

### TabsList

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"default" \| "line"` | `"default"` | Visual style variant |
| `shape` | `"rounded" \| "pill"` | `"rounded"` | Trigger corner radius |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Tab list orientation |
| `scrollable` | `boolean` | `false` | Scroll horizontally in a Reel, with edge fades and bare chevrons. |
| `morphing` | `boolean` | `false` | Collapse inactive triggers to icon-only; only the active trigger shows its `TabsTriggerLabel` |

### TabsTrigger

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `BaseTabs.Tab.Value` | - | Unique tab identifier |
| `disabled` | `boolean` | `false` | Whether the tab is disabled |

### TabsTriggerLabel

Wraps a tab's text label so it can collapse to width 0 in `morphing` mode.
Outside morphing mode it behaves like a plain `<span>`.
