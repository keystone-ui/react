## Usage

```tsx
import {
  Card,
  CardHeader,
  CardTitle,
  CardDescription,
  CardAction,
  CardContent,
  CardFooter,
} from "@keystoneui/react/card";
```

### Filled and outline surfaces

Card has 2 surface tiers, set with `variant`. `filled`, the default, paints `bg-card`. `outline` has no fill, so the page shows through. Use it for chart and table panels, where a filled card on a filled page reads as two stacked surfaces.

Both variants draw a ring, not a border. A ring is a box-shadow with no layout impact, while a border insets the content box by 1px, so switching a row of cards between variants would shift every child. `outline` rings `border` at full strength, and `filled` rings `border-muted`, the same color at half alpha. With no fill, the edge is the only thing that defines an `outline` card, so it's stronger.

### Title weight

`CardTitle` is `font-medium`, the same as `DrawerTitle`, `AlertDialogTitle`, `AlertTitle`, `EmptyTitle` and `ItemTitle`. Every `*Title` part in the library matches except `ModalTitle`, which is `font-semibold text-lg` because a dialog heading is a different tier.

A dense dashboard panel can need a heavier title: its heading competes with a table or a chart, where a login card's title competes with nothing. Set the weight with `className` instead of changing the component. Use the same weight on every panel of a page, because one heavier heading beside a lighter one reads as a mistake:

```tsx
<CardTitle className="font-semibold">Top pages</CardTitle>
```

### A table in a titled card

Put the table in `CardContent`. It then shares the card's horizontal padding with the title, so the heading, the row separators and the cell text all line up:

```tsx
<Card variant="outline">
  <CardHeader>
    <CardTitle>Delivery by squad</CardTitle>
  </CardHeader>
  <CardContent>
    <Table>{/* ... */}</Table>
  </CardContent>
</Card>
```

No other spacing change is needed. The cell text sits `px-2` further in than the title, which is the table's own column gutter. Use `size="sm"` for a denser panel.

**Don't zero the spacing for a titled table.** A flush table under a padded `CardHeader` indents the heading 3 times further than the columns (24px against 8px), and the card keeps its vertical padding below the last row. The result looks like a mistake.

### A card that is only a table

Zero `--card-spacing` only for a card with no title and no description, such as an explorer table that is the whole card. The header row then sits against the card's edge, and `overflow-hidden` clips the table's square corners to the card radius:

```tsx
<Card variant="outline" className="[--card-spacing:0px]">
  <Table>{/* ... */}</Table>
</Card>
```

[Styling hooks](/docs/concepts/styling-hooks) explains how `--card-spacing` reaches every part, and why `size` resolves it through CVA.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `"md" \| "sm" \| "xs"` | `"md"` | The size variant of the card. Resolves `--card-spacing`, which every sub-part reads. |
| `variant` | `"filled" \| "outline"` | `"filled"` | Surface treatment. `outline` drops the fill for panel use. |
| `className` | `string` | - | Additional CSS classes |
