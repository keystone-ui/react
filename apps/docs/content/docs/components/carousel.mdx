```tsx
  Carousel,

  CarouselItem,
  CarouselPrevious,
  CarouselNext,
  CarouselDots,
} from "@keystoneui/react/carousel";
```

## Composition

```text
Carousel
├── CarouselContent
│   └── CarouselItem
├── CarouselPrevious
├── CarouselNext
├── CarouselDots
└── CarouselCounter
```

`CarouselContent` must be the first child of `Carousel`. The arrows are centered on the
first row of the carousel grid, so `CarouselDots` and `CarouselCounter` below the slides
never pull them off-center.

## RTL

RTL support in Keystone UI is partial: Base UI handles keyboard navigation and popup positioning when you supply a `DirectionProvider`, but the library's own spacing is written with physical utilities and does not mirror. See [the RTL guide](/docs/rtl) for what works today.

## API Reference

### Carousel

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Scroll direction |
| `opts` | `CarouselOptions` | - | Embla Carousel options |
| `plugins` | `CarouselPlugin[]` | - | Embla Carousel plugins |

### CarouselItem

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | - | Additional CSS classes for sizing |
