## Usage

Import the parts from the `popover` subpath.

```tsx
import {
  Popover,
  PopoverTrigger,
  PopoverContent,
  PopoverHeader,
  PopoverTitle,
  PopoverDescription,
  PopoverArrow,
  PopoverClose,
} from "@keystoneui/react/popover";
```

## Composition

`PopoverContent` holds an optional header, an arrow and a close button.

```text
Popover
├── PopoverTrigger
└── PopoverContent
    ├── PopoverHeader
    │   ├── PopoverTitle
    │   └── PopoverDescription
    ├── PopoverArrow
    └── PopoverClose
```

A Popover opened from inside a Modal or Drawer appears above it. [Popup layering and modality](/docs/concepts/popup-layering) explains the scale.

## API reference

### PopoverContent

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"bottom"` | Preferred placement side |
| `align` | `"start" \| "center" \| "end"` | `"center"` | Alignment along the side axis |
| `sideOffset` | `number` | `4` | Offset from the trigger in pixels |
| `className` | `string` | - | Additional CSS classes |
